
## 🧑‍💻 基礎程式設計(C++)每週練習作業 Week 1– now

> 包含每週的 C++ 課堂練習，內容涵蓋輸入輸出、變數運算、函式撰寫、亂數與檔案處理等主題。  
> This repository contains six weeks of C++ programming exercises, covering topics such as I/O, variables, functions, random numbers, and file operations.


### Key Learning Points

| 作業     | 主題              | 學習目標                                                         |
| -------- | ----------------- | ---------------------------------------------------------------- |
| lab 1  | 基本輸出          | 熟悉 `cout` 與 `endl`                                             |
| lab 2  | 變數與函式        | 理解常數宣告、基本運算、函式呼叫                                   |
| lab 3  | 條件判斷          | 熟悉 `if`, `else`, `switch`                                      |
| lab 4  | 迴圈與亂數        | 使用 `for`, `while`, `do-while` 與 `random_device`               |
| lab 5  | 陣列與字串        | 學習字串處理與多筆資料操作                                        |
| lab 6  | 檔案處理          | 使用 `ofstream`、`ifstream` 寫入/讀取資料                         |
| lab 7  | 遞迴與數值判斷    | 透過 Climbing Stairs 題目練習遞迴呼叫與路徑列舉，並在 Palindrome Number 中運用整數反轉、輸入驗證與 `do-while` 迴圈，強化數值判斷與函式設計觀念  |
| lab 9  | 陣列運算與矩陣計算 | 綜合練習一維/二維陣列：包含線性搜尋、插入排序、陣列複製、循環位移運算，以及 2×3 與 3×4 矩陣相乘後求和，熟悉巢狀迴圈與索引操作在實際數值計算中的應用  |
| lab 11 | 結構化資料與規格檢查 | 透過輸出 JSON 格式與讀取 CSV 檔案，練習 `getline`、`stringstream`、`stoi`/`stod`、格式化輸出等技巧，實作平均功耗、總面積與規格判斷邏輯，練習處理結構化資料與基本資料分析  |
| lab 12 | 指標與動態記憶體    | 透過整數陣列搜尋與反轉題目，練習指標運算、位址回傳、`nullptr` 判斷、`new[]/delete[]` 記憶體管理，理解指標在陣列走訪與就地交換中的應用  |
| lab 13 | 結構與動態二維陣列  | 透過學生成績與矩陣加法題目，練習 `struct` 設計、字元陣列與字串處理、函式回傳指標、動態配置二維陣列與釋放流程，強化資料組織與模組化實作能力  |
| lab 14 | 綜合實作與資料聚合  | 結合 `struct`、函式參數傳址與矩陣運算，實作 Pokemon 資料讀取、最大配對索引搜尋、列/行/對角線總和比較等邏輯，練習多步驟輸入解析與綜合演算法設計  |
